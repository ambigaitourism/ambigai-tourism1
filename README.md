# SR Ambigai Tourism Website

Responsive tourism website with WhatsApp cab booking, fleet, tour packages (Ooty, Coonoor, Pykara, Coimbatore, Mysuru, Kerala and Coorg), and a review form.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open the Pages URL GitHub displays.

Bookings open WhatsApp with the trip details. Reviews are only held in the current page session; a database is needed for permanent public reviews.
