Ambigai Tourism website
A responsive, beginner-friendly static website for Ambigai Tourism, Ooty.
Files
`index.html` — website content and booking form
`style.css` — layout, colours, responsive design and animations
`script.js` — mobile menu and WhatsApp booking form
Preview on your computer
Extract the ZIP file.
Open the `ambigai-tourism-website` folder.
Double-click `index.html` to preview the website in your browser.
Publish with GitHub Pages
Open your GitHub repository.
Upload the files inside this folder (`index.html`, `style.css`, `script.js`, and `README.md`) to the repository root. Do not upload only the ZIP.
Commit the changes.
In GitHub, open Settings → Pages.
Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
Open the Pages URL shown on that screen.
Booking
The booking form opens WhatsApp with the customer's details pre-filled. It does not take payment or confirm a booking automatically. The customer sends the message and your team confirms availability.
Before publishing
Check the phone number, email and address in `index.html`.
Replace the sample destination photos with your own licensed photos if desired.
Add genuine customer reviews only after receiving permission from customers.
The site uses Google Fonts and photo links from Unsplash, so an internet connection is needed for those assets.
